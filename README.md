# Персональный сайт с AI-ассистентом для представления профессиональных компетенций

Дипломный проект по разработке AI-агентов.  
Автор: **Андрис Янчевскис**.

---

## 1. Назначение проекта

Проект представляет собой персональный сайт-портфолио со встроенным специализированным AI-ассистентом. Главная задача системы — предоставить потенциальным работодателям, клиентам и партнерам удобный диалоговый интерфейс для анализа профессиональных компетенций Андриса Янчевскиса на основе исключительно подтверждённых фактов (опыт работы, образование, стек технологий, выполненные проекты).

Если запрашиваемая информация отсутствует или еще не верифицирована, ассистент прямо сообщает об этом ограничении, исключая генерацию недостоверных сведений («галлюцинаций»).

---

## 2. Текущий статус (Sales Agent & FAISS RAG)

В проекте реализован полнофункциональный **AI Sales Agent** на базе **OpenAI** и векторной базы знаний **FAISS**:
- База знаний собрана из 21 подтверждённого документа со страниц сайта, публичного профиля GitHub (`@ajandris`) и резюме (CV 2026);
- Реализован пайплайн векторной индексации (`scripts/build_rag_knowledge_base.py`) с эмбеддингами `text-embedding-3-small` (1536 измерений) и косинусным поиском FAISS;
- Sales Agent анализирует требования вакансий и проектов посетителей, сопоставляет их с реальными навыками Андриса, указывает прямые совпадения, смежные преимущества, честные ограничения и ссылки на проекты;
- Реализован автоматический перехват контактов из текста диалога и через прямую форму лидогенерации с отправкой уведомлений на настроенный email (`SMTP_TO_EMAIL`);
- Набор из 56 автоматических тестов на **pytest** полностью покрывает работу сайта, API, базы знаний и отправку лидов.

## 3. Технологический стек

- **Бэкенд:** Python 3.12+, FastAPI, Uvicorn, Jinja2, Pydantic v2, pydantic-settings, python-dotenv, SQLite.
- **AI / RAG стек:** OpenAI API (модели `gpt-4o-mini`, `text-embedding-3-small`), векторная база данных FAISS (косинусное сходство, `IndexFlatIP`), Markdown база знаний.
- **Интеграции:** SMTP-уведомления (aiosmtplib/smtplib), Google reCAPTCHA v2/v3, ReportLab (генерация PDF).
- **Фронтенд:** HTML5 (семантическая верстка, доступность ARIA), CSS3 (дизайн-система на CSS Custom Properties, адаптивная сетка, поддержка `prefers-reduced-motion`), нативный JavaScript (без сторонних тяжелых фреймворков).
- **Тестирование:** pytest, httpx, TestClient.

## 5. Требования и установка

### 5.1. Требования к окружению
- Python версии **3.12** или новее.
- Менеджер пакетов `pip`.

### 5.2. Создание виртуального окружения
В корневой папке проекта выполните:
```bash
python -m venv .venv
```

### 5.3. Активация виртуального окружения

- **Windows PowerShell:**
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  *(Если выполнение скриптов заблокировано: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`)*

- **Windows CMD:**
  ```cmd
  .\.venv\Scripts\activate.bat
  ```

- **Linux / macOS:**
  ```bash
  source .venv/bin/activate
  ```

### 5.4. Обновление pip и установка зависимостей
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 6. Настройка конфигурации (`.env`)

Создайте рабочий файл `.env` на основе шаблона `.env.example`:

- **Windows (PowerShell):**
  ```powershell
  Copy-Item .env.example .env
  ```
- **Linux / macOS:**
  ```bash
  cp .env.example .env
  ```

Содержимое `.env.example`:
```dotenv
APP_NAME=Персональный AI-ассистент Андриса Янчевскиса
APP_ENV=development
OPENAI_API_KEY=
LLM_MODEL=
EMBEDDING_MODEL=
VECTOR_DB_PATH=./rag
```

> **ВНИМАНИЕ: Безопасность секретов!**  
> Никогда не публикуйте и не добавляйте в Git файлы `.env` с реальными API-ключами. Файл `.env` включён в `.gitignore`.

## 8. Запуск автоматических тестов

Запуск тестов осуществляется командой:
```bash
pytest
```
Или с подробным выводом:
```bash
pytest -v
```

Тесты проверяют:
1. `GET /health` возвращает статус HTTP 200, `"status": "ok"` и корректное имя сервиса из Pydantic Settings.
2. `GET /` возвращает HTTP 200, содержит `<html lang="ru">`, имя «Андрис Янчевскис», блок «AI-ассистент» и не содержит текста `Lorem ipsum`.
3. Корректную доступность статических файлов стилей (`/static/css/styles.css`) и скриптов (`/static/js/chat.js`).
4. Поведение эндпоинта `/api/chat`, возвращающего ответ Sales Agent со ссылками на RAG-источники.
5. Автоматическое распознавание контактов и валидацию формы `/api/chat/lead`.
6. Векторную базу FAISS: добавление, поиск по косинусному сходству, сохранение и загрузку индекса.

---

## 9. Построение векторной базы знаний RAG

Для пересборки базы знаний и обновления векторных эмбеддингов FAISS выполните:
```bash
python scripts/build_rag_knowledge_base.py
```

Скрипт выполняет:
1. Загрузку подтверждённых документов из внешнего Markdown-файла базы знаний `rag/knowledge_base/knowledge_base.md`;
2. Генерацию векторных представлений через модель OpenAI `text-embedding-3-small` (1536 измерений);
3. Построение индекса `IndexFlatIP` (косинусное сходство) и сохранение в `./rag/index.faiss` и `./rag/chunks.json`;
4. Контрольный тестовый поиск по ключевым запросам компетенций.
