# Персональный сайт с AI-ассистентом для представления профессиональных компетенций

Дипломный проект по разработке AI-агентов.  
Автор: **Андрис Янчевскис**.

---

## 1. Назначение проекта

Проект представляет собой персональный сайт-портфолио со встроенным специализированным AI-ассистентом. Главная задача системы — предоставить потенциальным работодателям, клиентам и партнерам удобный диалоговый интерфейс для анализа профессиональных компетенций Андриса Янчевскиса на основе исключительно подтверждённых фактов (опыт работы, образование, стек технологий, выполненные проекты).

Если запрашиваемая информация отсутствует или еще не верифицирована, ассистент прямо сообщает об этом ограничении, исключая генерацию недостоверных сведений («галлюцинаций»).

---

## 2. Текущий статус (MVP 0.3.0)

В рамках текущей итерации реализован полноценный рабочий веб-сервис:
- Полностью спроектирована и оформлена фронтенд-структура со всеми обязательными разделами на русском языке;
- Сайт наполнен исключительно подтвержденными данными (для неполных данных предусмотрены нейтральные индикаторы);
- Создан законченный пользовательский интерфейс AI-ассистента с примерами вопросов;
- В соответствии с требованиями итерации реальные вызовы к LLM и RAG **не имитируются** — при отправке запроса интерфейс выдает честное уведомление о том, что интеграция подготавливается;
- Реализовано серверное приложение на базе **FastAPI**, конфигурация на **Pydantic Settings** (v2) и набор автоматических тестов на **pytest**.

---

## 3. Технологический стек

- **Бэкенд:** Python 3.12+, FastAPI, Uvicorn, Jinja2, Pydantic v2, pydantic-settings, python-dotenv.
- **Фронтенд:** HTML5 (семантическая верстка, доступность ARIA), CSS3 (дизайн-система на CSS Custom Properties, адаптивная сетка, поддержка `prefers-reduced-motion`), нативный JavaScript (без сторонних тяжелых фреймворков).
- **Тестирование:** pytest, httpx, TestClient.
- **Будущий стек AI/RAG (этап 4):** OpenAI API / совместимый провайдер, модель эмбеддингов, векторная БД Qdrant.

## 5. Требования и установка

### 5.1. Требования к окружению
- Python версии **3.12** или новее.
- Менеджер пакетов `pip`.

### 5.2. Создание виртуального окружения
В корневой папке проекта выполните:
```bash
python -m venv .venv
```

### 5.3. Активация виртуального окружения

- **Windows PowerShell:**
  ```powershell
  .\.venv\Scripts\Activate.ps1
  ```
  *(Если выполнение скриптов заблокировано: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`)*

- **Windows CMD:**
  ```cmd
  .\.venv\Scripts\activate.bat
  ```

- **Linux / macOS:**
  ```bash
  source .venv/bin/activate
  ```

### 5.4. Обновление pip и установка зависимостей
```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 6. Настройка конфигурации (`.env`)

Создайте рабочий файл `.env` на основе шаблона `.env.example`:

- **Windows (PowerShell):**
  ```powershell
  Copy-Item .env.example .env
  ```
- **Linux / macOS:**
  ```bash
  cp .env.example .env
  ```

Содержимое `.env.example`:
```dotenv
APP_NAME=Персональный AI-ассистент Андриса Янчевскиса
APP_ENV=development
OPENAI_API_KEY=
LLM_MODEL=
EMBEDDING_MODEL=
VECTOR_DB_PATH=./data/qdrant
```

> **ВНИМАНИЕ: Безопасность секретов!**  
> Никогда не публикуйте и не добавляйте в Git файлы `.env` с реальными API-ключами. Файл `.env` включён в `.gitignore`.

## 7. Запуск приложения

Для запуска сервера разработки используйте команду:
```bash
uvicorn app.main:app --reload
```

После старта доступны следующие локальные адреса:
- **Главная страница:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Проверка состояния (Health check):** [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)
- **Интерактивная документация (Swagger UI):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 8. Запуск автоматических тестов

Запуск тестов осуществляется командой:
```bash
pytest
```
Или с подробным выводом:
```bash
pytest -v
```

Тесты проверяют:
1. `GET /health` возвращает статус HTTP 200, `"status": "ok"` и корректное имя сервиса из Pydantic Settings.
2. `GET /` возвращает HTTP 200, содержит `<html lang="ru">`, имя «Андрис Янчевскис», блок «AI-ассистент» и не содержит текста `Lorem ipsum`.
3. Корректную доступность статических файлов стилей (`/static/css/styles.css`) и скриптов (`/static/js/chat.js`).
4. Поведение эндпоинта `/api/chat`, возвращающего статус готовности.

## 9. План следующей итерации (Этап 4)

В следующей итерации дипломного проекта будут реализованы:
1. Подготовка и структурирование корпуса документов в `knowledge_base/raw/` (проекты TheDecisionPoint, simpleshop, postgres_db_desc, candlemania, tic-tac-toe);
2. Пайплайн чанкинга и генерации эмбеддингов с сохранением в векторную базу данных Qdrant;
3. Двухэтапная цепочка LLM:
   - Первый промпт: классификация намерения и извлечение ключевых поисковых терминов;
   - Векторный поиск релевантных подтвержденных чанков;
   - Второй промпт: строгая генерация ответа только по найденному контексту с указанием источников;
4. Связка бэкенда с фронтенд-чатом в режиме реального времени;
5. Запуск экспериментов (evaluation) с вариацией размера чанков и гиперпараметров поиска.
